# WWAScript 仕様書 (WWA Wing 解析補助用)

WWAScriptは、JavaScriptをベースにWWA Wing（HTML5版WWA）向けにカスタマイズされた独自言語です。セキュリティ確保のため、エンジン側で一度文字列として読み込まれ、独自の構文解析（パース）を経て実行されます [1]。

## 1. JavaScriptとの主な構文の違い

### 変数宣言
- **宣言の禁止**: `var`, `let`, `const` による変数宣言は一切行えません [1, 2]。
- **ユーザー定義変数**: 全ての変数操作は、事前定義されたユーザー定義変数 `v` を介して行います [1]。

### データ型の制限
- **引数の制約**: 関数の引数には `number` または `string` のみ使用可能です。`Object`, `null`, `undefined` を直接関数の引数に渡すことはできません [1]。
- **代入の制約**: 後述する `v[N]`（数値添字）には数値しか代入できません [1]。

### 制御構文の制約
- **for文の変数**: ループ変数として使用できるのは `i`, `j`, `k` または `LP[x]` (Loop Pointer) のみに限定されます [3, 4]。
- **無限ループ防止**: 1回のスクリプト実行における処理回数はデフォルトで **10,000回** に制限されています。これを超えると強制終了します（`LOOPLIMIT` 変数で調整可能）[3, 5]。

## 2. 変数システム

### 2.1 組み込み変数 (グローバル)
ゲームの状態を直接参照・操作するための予約済み変数です [5-8]。

| 変数名 | 内容 | 備考 |
| :--- | :--- | :--- |
| `HP` / `HPMAX` | 現在の生命力 / 生命力最大値 | 0は無制限 |
| `AT` / `DF` | 攻撃力 / 防御力 | |
| `GD` | 所持金 | |
| `STEP` | 移動回数 | |
| `PX` / `PY` | プレイヤーの現在座標(X, Y) | |
| `X` / `Y` | スクリプト実行パーツの座標 | イベント実行時はプレイヤー座標 |
| `ID` | 実行パーツの番号 | イベント実行時は -1 |
| `m[x][y]` | 座標(x, y)の背景パーツ番号 | |
| `o[x][y]` | 座標(x, y)の物体パーツ番号 | |
| `ITEM[1, 3, 6, 7, 9-16]` | アイテムボックスのスロット(1-12) | 0は空 |
| `PDIR` | プレイヤーの向き | 2:下, 4:左, 6:右, 8:上 |

### 2.2 ユーザー定義変数 `v`
ユーザーが自由に値を保持できる変数です。2種類の記法で挙動が異なります [1, 6]。

- **`v[N]` (数値添字)**:
  - `N` は 0 〜 255 の自然数。
  - 格納できるのは **数値のみ**。文字列やオブジェクトは不可。
- **`v["name"]` (名前付き)**:
  - 文字列をキーとする連想配列形式。
  - 数値、文字列、**Object（連想配列）**、配列を格納可能。
  - 複雑なデータ構造（例：`v["player"]["HP"]`）の構築に使用。

### 2.3 Loop Pointer `LP[x]`
4重以上の深いネスト（多重ループ）を行う際に使用する特殊な配列型ループ変数です [15]。
- `LP`, `LP[1]`... のように自然数を添字に使用します。
- 使用可能かどうかの判定には `IS_NUMBER(LP[x])` を利用します [16, 17]。

## 3. 主要関数リファレンス

### システム操作
- `MSG("文字列")`: メッセージウィンドウを表示。`\n` で改行可能 [9, 18]。
- `LOG(value)`: ブラウザのコンソールに出力 [9, 19]。
- `RAND(V)`: 0 以上 V 未満の乱数を返す [9, 18]。
- `EXIT()`: スクリプトの実行を即座に中断する [12, 17]。
- `SOUND(N)`: 指定したサウンド番号を再生 [9, 20]。

### プレイヤー・マップ操作
- `JUMPGATE(X, Y)`: 指定座標へワープ [9, 18]。
- `CHANGE_PLAYER_IMAGE(X, Y)`: プレイヤーの画像を画像ファイル上の座標(パーツ単位)で変更 [10, 21]。
- `PARTS(ID1, ID2, TYPE)`: マップ上の全パーツ ID1 を ID2 に置換 [10, 22]。
- `GET_IMG_POS_X/Y(id, type)`: パーツの画像ファイル上の座標を取得 [12, 18, 23]。

### アイテム操作
- `HAS_ITEM(ID)`: パーツ番号 ID のアイテムを所持していれば true [10, 24]。
- `REMOVE_ITEM(ID, ALL)`: 指定したアイテムを削除。ALL=1 で全削除 [10, 20]。

### 高度な描画 (ピクチャ機能)
- `PICTURE(id, params)`: 画面上の任意座標に画像やテキストを表示 [17, 25]。
  - `params` はオブジェクト形式で、`pos` (座標), `text` (文字列), `opacity` (不透明度), `time` (表示時間), `move` (移動) などを指定。

## 4. 特殊な演算と挙動
- **文字列結合**: `+` 演算子による結合や、テンプレートリテラル `${HP}` が使用可能。
- **オブジェクトのコピー**: `CLONE(v["A"])` を使用することで、参照ではなく値（構造丸ごと）をコピー可能 [13]。
- **外部スクリプト**: `./script` フォルダ内の `.js` ファイルで定義された関数を WWAScript から呼び出すことが可能 [26]。

Claude CLIでソースコードを解析する際、特に 「変数宣言の有無」 と 「v変数の使い分け（数値キー vs 文字列キー）」 に着目すると、ロジックの意図を正確に把握できるはずです。
